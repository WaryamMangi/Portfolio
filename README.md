# Waryam Mangi — Portfolio

React + Vite + TypeScript + Tailwind CSS.

    npm install
    npm run dev      # local dev server
    npm run build    # production build in dist/

- All content: `src/data/portfolio.ts` (text, links, projects, experience, certifications).
- Hero photo: replace `src/assets/waryam-cutout.webp` with a transparent-background cutout (same filename, .webp).
- Project screenshots: put files in `public/projects/` and list them in each project's `images` array (e.g. `"/projects/rag-1.png"`), 1 to 4 per project.
- Social links: set `socials.github` and `socials.linkedin` in the data file; set `github` / `live` per project.
